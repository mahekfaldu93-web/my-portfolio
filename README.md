# Mahek Portfolio

A modern and responsive **personal portfolio website** created using **React.js**.
It showcases my skills, services, recent projects, and contact information.

## 🚀 Features

* Responsive design
* Modern dark theme
* Navigation bar
* Hero section
* Services section
* Recent works/projects
* Skills section
* Contact section
* Mobile-friendly layout
* Smooth scrolling
* Hover effects

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML
* CSS
* Bootstrap

## 📂 Sections

* **Home** – Introduction and profile
* **Services** – Web development services
* **Works** – Recent projects
* **Skills** – Technical skills
* **Contact** – Contact information

## ▶️ How to Run

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.
